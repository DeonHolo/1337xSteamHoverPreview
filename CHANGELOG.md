# Changelog

## 5.00 — Unreleased

Changes since public version 4.1.

- Show actual Steam tags in the first useful preview, without temporary genre replacements or needing a second hover.
- Improve preview loading and cached repeat hovers, with priority for the game you are browsing.
- Repair Steam review retrieval, including recently released games, and show clearer no-review and unavailable states.
- Improve title matching for typos, punctuation, release suffixes, commercial editions and localized names; follow verified DLC links to the base game.
- Search by name inside Choose Steam game… or Wrong game?, select from closest-name suggestions, and save the correct game for future visits. AppID and Steam URL entry are also available.
- Add a Settings entry in the userscript manager’s extension menu for nearby/page/on-hover preloading, preview theme and review filtering, plus tools to manage saved matches and cached data.
- Improve keyboard access to previews and focus handling during actions.
- Use a small Steam logo for the store action.
