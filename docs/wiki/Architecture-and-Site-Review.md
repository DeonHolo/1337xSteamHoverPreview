# 1337x architecture

The public root [1337xSteamHoverPreview.js](../../1337xSteamHoverPreview.js) is generated by scripts/build.mjs. The script's install identity remains intact; the userscript header is maintained in src/userscript-header.txt.

| Module | Responsibility |
| --- | --- |

| scripts/build.mjs / sync-core.mjs | Dependency-free standalone build and version/hash-locked shared-source distribution |

The checked-in vendor snapshot makes this repository buildable without the companion checkout. Change shared source in the CS.RIN repo and synchronize it rather than editing the vendor files.

## Runtime path

The adapter returns a stable site item key, raw title, cleaned title, source URL, and site utilities. The engine resolves a confident base AppID or a validated saved correction; query aliases reuse AppID metadata. The controller waits for actual tags or a bounded unavailable state before its first meaningful card. Reviews use a lower-priority independent request and only replace their own row. Hover generations and per-consumer cancellation prevent old responses from altering a newer game.

Preload uses the same loadPreview pipeline as hover, so it warms actual tags rather than saving genres. Shared request jobs promote active hover consumers, deduplicate resource requests, cap concurrency, respect hidden state and cooldowns, and abort when abandoned. Cache clearing uses a generation and cross-tab clear epoch; reset markers prevent stale correction resurrection.

## Site behavior retained and repaired

- Explicit Games, Windows and PC categories/icons qualify rows on Games, search and uploader pages. Windows-style flaticon-apps rows work even without a Games link, heading or uploader column; hover and preload share this eligibility check. Mixed-page uploader/release markers remain additional hints.
- One cleanup policy feeds hover and preload. Ghost, Lost, Demonologist, subtitles, seasons, and Unicode survive protected parsing.
- A single magnet controller serves card and theatre. Source pages use same-origin URL validation, timeout, in-flight reuse, and a small completed cache. Magnet URIs require a valid torrent identity.
- The failure card retains the source action; errors offer Retry and Open torrent page. It never claims a torrent client started a transfer.
- The original public filename and native light palette are retained; shared theatre class names no longer imply a forum-only component.
